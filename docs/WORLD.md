# Fictional World Gazetteer

Everything named on the site is invented. Use only the names below (or new ones in the same style) and add new ones here so every writer stays consistent. See ADR-021.

**Allowed real references:** the United States and the state of California (as the setting), the 707 area code with 555-01xx/02xx numbers, and generic laws, public programs and standards that any US university must mention: FAFSA, Pell Grant, Cal Grant, California Dream Act, Title IX, FERPA, the U.S. Department of Education, ADA/Section 504, WCAG, and APA/MLA/Chicago citation styles.

**Never real:** towns, counties, rivers, parks, landmarks, other colleges and universities, accreditors, athletic associations, companies and products, journals and conferences, hospitals, tribal nations, or people.
